# 보류 기능 조사 보관 — 시간축 배분 (D76)

> 2026-08-19 조사, 소유자 판정으로 보류. 세법 전수 조사는 `docs/stage-1-discovery/tax-rules-report.md` 29절에 있다.
> 이 문서는 제품·설계 조사의 결론만 압축 보관한다. 되살릴 때 이 문서와 29절, D76을 함께 읽는다.

## 소유자의 원래 요청

현시점 배분만이 아니라 시간이 지나며 배분이 어떻게 바뀌어야 하는지 보여주기.
소유자가 든 요인: ①연봉 인상→공제율 변동 ②연금 누적액→종합소득세 ③주택 구매 ④결혼 ⑤수익률 변동.
소유자가 낸 UI 안: (가) 시간축 바 차트, (나) 슬라이더 헤드→도넛 변형.

## 제품 조사 결론 (product-planner)

- **가정 기반 전체 투영은 requirements.md 7절 비범위(「다년도·복리 시뮬레이션 제외」, 게이트 1 확정)와 정면 충돌** — 기능 추가가 아니라 닫힌 결정을 여는 일이다.
- 타깃(연말정산 절세 확인 욕구)의 방문 동기 근거 어디에도 「10년 뒤 배분」이 없다. 국내 경쟁 3곳(쿼터백·토스뱅크·뱅크샐러드) 모두 시간축 없음. 해외 glide-path 계산기류는 주식/채권 자산배분 문제라 우리 문제(절세계좌 간 납입 배분)와 입력 성격이 다르다.
- **새 헤더 탭이 아니다** — 헤더 탭은 브랜드 이름표(D72). 만든다면 결과 영역 안 (기본 접힌) 보조 섹션 — 기존 「확정/개정안 시나리오 탭」·「근거 접힘」 패턴의 연장.
- 가정 없는 「이정표」만 v1로 성립한다. 전체 투영을 열려면: 게이트 차원 비범위 해제 + ISA 수익률 수준의 방어선(기본값·힌트 없음) + 수요 실재 근거 + 개인 지시형으로 읽히지 않는 표현 설계 — 넷 다 먼저 있어야 한다.

## 설계 조사 결론 (designer)

- **(가) 시간축 스택바 기각**: `ScenarioStackBar`의 기존 의미(배타적 대안 비교, 최대 4행)와 형태 충돌 + 은퇴까지 20~40행이라 「한눈 비교」 전제 붕괴. 재사용처럼 보이지만 실제로는 검증 안 된 새 컴포넌트다.
- **(나) 슬라이더-도넛 기각**: 도넛은 거저 재사용하지만 한 시점만 보여 「언제 꺾이나」에 답하지 못한다. 모바일 350px에 30년이면 연간 해상도 ~10px/년 — 스냅이 필수인데 이정표 스냅을 넣는 순간 제3안이 된다. 이 저장소에 드래그류 컨트롤 전례가 없다.
- **제3안 권고 — 이정표 타임라인 + 탭 스냅샷**: 배분이 실제로 바뀌는 시점만 점 마커로 찍은 축선. 마커 탭 → 도넛·AllocationBar가 그 시점 값으로 전환(C-3의 「행 클릭→도넛 전환」 동사 재사용). 신규 표면적은 축선 컴포넌트 하나 — 셋 중 최저 비용.

```
지금 ●──────────●────────────┄┄┄┄┄●┄┄┄┄┄┄┄┄┄┄┄┄◇
     │      ISA 만기        만 55세          (가정 구간)
     실선(확정 구간)          점선(가정 구간)
```

- **확정/가정 구분 — 이 기능의 가장 무거운 설계 문제**: `AccountBenefitStrip`의 D43 답(모양이 아니라 물리적 축 분리가 확실성을 가른다)은 **시간축에 이식되지 않는다** — 시간은 하나의 연속 축이라 자를 둘로 못 가른다. 여기서는 D28식 모양 구분이 오히려 맞다: 확정 구간 실선+채움 점+LawChip, 가정 구간 점선+윤곽 점+조건절 캡션. `data-excluded` 점선 토큰은 뜻이 달라 재사용 금지 — 새 토큰 필요. 가정이 시점 자체를 흔드는 이정표(예: ISA 여력 소진 시점)는 점이 아니라 구간(bracket) 마커.
- **미리 걸어둔 경고**: 「가정 구간을 채워 눈에 띄게 해달라」는 요구가 재현될 것이다(D38→D43 전례). 여기서는 물리적 분리 안전망이 없으므로 들어주면 안 된다.

## 세법 조사 핵심 (상세는 tax-rules-report.md 29절)

- 결정적 요인(A1, 지어낸 값 0): 만 55세 도달, ISA 의무가입 3년 만료, **ISA 총 납입한도 1억 소진(납입액 누계 — 수익률 불필요)**, 2027 시행일, 2029 일몰.
- 소유자 ②(누적액→종소세)는 수령 단계 조문 + 16.5% 분리과세 캡이라 오늘의 배분 근거가 아니다. ③(주택)은 방향 상쇄 미정 + IRP 중도인출 불이익은 이미 반영됨. ④(결혼)는 결혼세액공제 50만원뿐이고 2026-12-31 일몰.
- 방어선 판정: 수익률은 (a)(b)(c) 모두 서고, **연봉 경로는 (c)가 구조적으로 불가** — 총급여가 바로 공제율 조문이 걸리는 값이다. 층 1(결정적)·층 2(소득 동결 명시 전제)까지 선 안, 층 3(연봉 경로 입력)은 선 안이라 말하지 않는다.
