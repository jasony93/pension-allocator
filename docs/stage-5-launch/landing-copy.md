# 5단계 — 랜딩 카피

이 문서는 결과 화면(2단계 산출물, `screens.md`)의 문구를 대체하지 않는다. 그 문구는 이미 승인됐고 `designer` 소관이다. 이 문서가 담당하는 것은 **사람을 계산기로 데려오는 화면 밖 문구** — 블로그 글머리, SNS 게시물, 검색 결과 스니펫, 공유 캡션 — 이다.

## 0. 이 문서 전체가 지키는 제약

- 금지 어휘 10개(세무·세무사·택스·TAX·절세·컨설팅·환급·상담·자문·대행)를 예외 없이 쓰지 않는다. 부정형("~가 아닙니다")으로도 쓰지 않는다 — 결과 화면의 법정 고지(요소 ①②, `screens.md` 4.1절)는 이미 승인된 별도 산출물이고 그 문구가 이 단어들을 쓰는 것은 세무사법이 요구하는 표시이기 때문에 다르다. 이 문서의 카피는 그 조문상 의무가 없는 자리이므로 아예 쓰지 않는 편이 안전하다.
- 세법 수치(공제율·한도액·구체적 절감액)를 적지 않는다. "얼마를 아낀다"고 단정하지 않는다.
- "광고 없는 서비스입니다" 같은 영구 약속을 쓰지 않는다. 현재 사실만 적는다.
- 제휴·광고를 전제하는 카피를 쓰지 않는다.
- 특정 계좌 하나를 개인에게 지시하는 문장("당신은 IRP에 넣으세요")을 쓰지 않는다. 항상 "배분을 비교해 보여준다"는 서술을 쓴다.

## 1. 헤드라인 (A/B/C, 채널별로 골라 쓴다)

**A — 행동 유도형**
> 이번 달 남는 돈, 계좌 세 개에 어떻게 나눌까

**B — 문제 인식형**
> ISA·IRP·연금저축, 감으로 나눠 넣고 계셨나요

**C — 방법 서술형**
> 계좌 배분, 어림짐작 대신 계산으로

세 헤드라인 모두 금액·비율·확정적 절감 표현이 없다. "감으로", "어림짐작" 같은 표현으로 기존 문제를 짚되, 해결책도 확정적 결과("얼마를 아낀다")가 아니라 방법("계산으로 비교한다")으로 제시한다.

## 2. 부제 (헤드라인과 세트로 쓴다)

```
나이·총급여·월 납입 여력을 넣으면 ISA·IRP·연금저축에
어떻게 나눌지 세법 규칙 그대로 계산해서 보여줍니다.
기본안 하나만 주지 않고 대안과 함께 비교합니다.
```

짧은 버전(SNS·소셜 카드용, 100자 내외):
```
값을 넣으면 ISA·IRP·연금저축 배분안을 계산해 기본안과 대안으로 비교해 보여줍니다.
```

## 3. 기능 설명 불릿 (본문·상세 소개용)

- 나이·총급여·월 납입 여력만 넣으면 계좌별 배분안이 나옵니다.
- 기본안 하나가 아니라 대안 1~2개를 함께 비교해서 보여줍니다.
- 계산에 쓴 법령 조항을 결과 화면에서 그대로 확인할 수 있습니다.
- 입력값은 이 브라우저 안에서만 쓰이고 서버로 전송되지 않습니다.
- 특정 금융상품이나 금융회사를 추천하지 않습니다.

## 4. 행동 유도 문구 (CTA)

| 맥락 | 문구 |
|---|---|
| 1차 CTA (계산기로 이동) | `지금 배분 계산해보기` |
| 2차 CTA (짧은 버전, 버튼 폭이 좁을 때) | `계산기 열어보기` |
| 공유 유도 | `내 배분 결과 확인해보기` |
| 재방문 유도(카카오톡 채널 리마인드 등) | `올해 배분, 다시 확인해보기` |

"계산하기" 버튼이 없는 화면 구조(`screens.md` 3.2절)와 헷갈리지 않도록, 이 CTA들은 전부 **화면 밖(블로그·SNS)에서 계산기 자체로 이동시키는 링크 텍스트**다. 화면 안에는 이런 버튼이 없다.

## 5. 고지 문구 (화면 밖 자리에서 쓰는 짧은 버전)

블로그 글 하단, SNS 프로필 소개, 공유 카드 등 화면 밖 자리에 붙이는 짧은 신뢰 문구다. 결과 화면의 여섯 요소 고지(`screens.md` 4.2절)를 대신하지 않는다 — 그건 계산 결과가 있을 때만 나오는 별도 블록이고, 이 문구는 사람이 계산기에 들어가기 *전*에 성격을 알 수 있게 하는 것이 목적이다.

```
이 계산기는 공개된 법령 규칙을 자동으로 적용한 계산 도구입니다.
개인별 신고·납부가 필요하면 자격을 갖춘 전문가의 확인을 받으시길 권합니다.
현재 이 서비스에는 제휴나 광고가 없습니다.
```

- 마지막 문장은 헌장 제품 원칙 8("지금 정하지 않은 것을 약속하지 않는다")에 따라 **현재형**으로만 썼다. "앞으로도 없습니다"라고 쓰지 않는다.
- "자격을 갖춘 전문가"는 금지 어휘를 피하면서 같은 의미를 전달하는 표현이다.

## 6. 공유 캡션 (SNS/카페 게시용, 서비스 소개 맥락)

특정 사용자의 계산 결과가 아니라 **서비스 자체를 소개**하는 게시물에 쓰는 캡션이다.

```
매달 남는 돈을 ISA·IRP·연금저축에 어떻게 나눌지 감으로 정하고 계셨다면,
값 몇 개만 넣어서 배분을 비교해보는 계산기입니다.
입력값은 브라우저 밖으로 나가지 않고, 계산에 쓴 법령 조항도 함께 보여줍니다.
```

## 7. 자체 금지어 검사

10개 금지 어휘(세무·세무사·택스·TAX·절세·컨설팅·환급·상담·자문·대행)를 문자열 검색으로 전체 재검토했다. **실제 등장은 0절 규칙 설명 문장 한 곳뿐이다** — "금지 어휘 10개(세무·세무사·택스·TAX·절세·컨설팅·환급·상담·자문·대행)를 예외 없이 쓰지 않는다"고 그 목록 자체를 나열한 것으로, 규칙을 진술하기 위한 인용이지 실제로 채택한 카피가 아니다. **1~6절(헤드라인·부제·불릿·CTA·고지·공유 캡션 — 실제로 화면 밖에서 쓰일 문구)에는 열 단어 중 어느 것도 등장하지 않는다.**

세법 수치(구체적 공제율·한도액·절감액)도 1~6절 어디에도 적지 않았다. "얼마를 아낀다"는 단정적 표현 대신 "배분을 계산해서 비교한다"는 서술만 썼다.
