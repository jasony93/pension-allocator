# 5단계 — 프로모션 플레이북

사람이 이 문서만 보고 그대로 실행할 수 있도록 채널별로 무엇을·언제·어떤 문안으로 올리는지, 계정 준비물은 무엇인지 적는다. **이 유닛은 실제 계정 생성·게시·광고 집행을 하지 않는다.** 아래는 전부 사람이 실행할 체크리스트다.

## 0. 출시 전 공통 준비물 — 계측 인프라 (관리자 결정 D18)

**이것이 빠지면 아래 어떤 채널을 실행해도 데이터가 0건이다.** 관리자가 `analytics-plan.md` 6-1절의 "권장"을 자체 호스팅 Umami로 확정했다(D18, 2026-08-09). `demand-validation-plan.md`의 지표 2(재방문율, Tier A 핵심 지표)가 `anon_id` 기반 7일 코호트 계산을 요구하는데, 관리형 쿠키리스 SaaS는 이 코호트 쿼리를 제공하지 않아 지표 자체가 측정 불가능해질 위험이 있었다 — 그래서 서버를 직접 운영하는 비용을 감수하고 Umami를 택했다.

**아래 순서는 채널 홍보를 시작하기 전에 완료해야 한다.**

- [ ] **서버 준비.** Umami를 올릴 서버(VPS 또는 컨테이너 호스팅) 1대를 준비한다. 사양은 이 규모(월 수천 세션)에서 최소형으로 충분하다.
- [ ] **Umami 인스턴스 설치.** 공식 배포 가이드대로 설치하고 관리자 계정을 만든다.
- [ ] **웹사이트 등록 및 website ID 발급.** Umami 관리자 화면에서 이 서비스를 사이트로 등록하고 발급되는 `website ID`(UUID)를 기록해 둔다.
- [ ] **앱에 website ID 설정.** `web-dev`가 `src/web/analytics.js`의 전송 계층에 이 ID를 연결한다 — **이 단계는 코드 변경이라 이 유닛이 하지 않는다.** `web-dev`에게 이 문서와 `analytics-plan.md` 6-1절을 전달해 확인을 받는다.
- [ ] **연결 확인.** 배포 전 테스트 세션 하나를 직접 발생시켜(계산기에서 결과 화면까지 도달) Umami 대시보드에 `result_shown` 이벤트가 실제로 찍히는지 확인한다. 이 확인 없이 채널 홍보를 시작하지 않는다 — 확인 전에 홍보를 시작하면 그 사이의 방문 데이터는 영구히 사라진다.
- [ ] **속성 화이트리스트 재확인.** `analytics-plan.md` 6-4절 표와 실제 Umami로 전송되는 속성을 대조해, 정의되지 않은 속성이 없는지 확인한다(이 확인은 `qa`가 게이트 4에서 이미 했던 절차와 같은 방식으로 게이트 5 전에 한 번 더 한다).

## 1. 공통 운영 원칙 (모든 채널에 적용)

- **금지 어휘 10개**(세무·세무사·택스·TAX·절세·컨설팅·환급·상담·자문·대행)를 어느 채널의 게시물·댓글·프로필 소개에도 쓰지 않는다.
- **세법 수치·확정적 절감액을 적지 않는다.** "얼마 아꼈다"는 후기·사례를 만들어 올리지 않는다.
- **댓글에서 개별 질문에 답하지 않는다.** 헌장의 기능 설계 원칙("사람이 개별 질문에 답하지 않는다")은 제품 기능뿐 아니라 채널 운영에도 그대로 적용된다 — 댓글로 "제 상황엔 얼마나 넣어야 하나요"라는 질문이 오면 개인화된 답을 달지 않는다. 아래 표준 응대 문구만 쓴다.

  ```
  직접 계산기에 값을 넣어보시면 그 조건에 맞는 배분을 확인하실 수 있어요.
  개별 상황에 대한 판단은 여기서 드리기 어려운 점 양해 부탁드립니다.
  ```

- **홍보로 읽히는 것과 정보로 읽히는 것의 경계를 지킨다.** 커뮤니티(카페·블라인드·자유게시판류)에서는 특히, 링크를 먼저 던지지 않고 정보 제공이 앞선다.
- **각 게시물에 "현재 제휴·광고 없음" 한 줄 또는 링크를 유지한다.** `landing-copy.md` 5절의 짧은 고지 문구를 프로필·게시물 하단에 반복한다.

## 2. 실행 순서와 우선순위

`channel-research.md` 3절의 우선순위를 그대로 따른다. 아래 1~5번을 이 순서로 준비한다. 6·7번(인스타그램/스레드 유료, 네이버 검색광고)과 커뮤니티 자유게시판은 이번 플레이북에서 다루지 않는다(위 open_questions).

| 순위 | 채널 | 착수 시점(0주 = 계측 인프라 완료 직후) |
|---|---|---|
| 1 | 네이버 블로그(오가닉 SEO) | 0주차 |
| 2 | 네이버 카페(정보 제공자로 참여) | 1주차(신뢰 쌓기 선행) |
| 3 | 유튜브 쇼츠(오가닉) | 2주차 |
| 4 | 블라인드(오가닉 게시글 공유) | 2주차(블로그 콘텐츠 완성 후) |
| 5 | 카카오톡 채널(리마인드용) | 1주차(개설만, 활성 발송은 시즌 진입 시) |

**시즌 참고.** 연말정산 성수기는 11~1월이다. 게이트 5 승인 시점(2026-08-09)에서 이 시기까지는 약 3개월 남았다 — `demand-validation-plan.md`의 8주 판정 기간이 이 시즌 전에 끝난다는 뜻이다. 따라서 초기 8주는 **성수기 트래픽 없이 지표를 재는 기간**이라는 것을 인지하고, 8주 이후에도 콘텐츠·채널 운영은 계속해 성수기 유입을 놓치지 않는다.
